# Admin hero media

`/admin/hero-media` manages `media_assets` mappings and shows the active resolution matrix. New uploads are stored in the exercise-media bucket under `hero-media/<scope>/`; legacy assets continue to use `assets/media-assets`.

Mappings have an immutable, environment-stable `asset_key`. Admin mutations are audited, deletion is a reversible deactivation, and promotion upserts production rows by `asset_key`. Mapping changes affect newly generated programs and bonus days; existing programs retain their stored image.

The authenticated API is rooted at `/admin/hero-media`: `list` and `coverage` are reads; create, partial update, image upload, deactivate/restore, single/bulk promotion, and production import provide the write operations. Uploads accept PNG, JPEG, or WebP up to 5 MB with a minimum width of 1080 px.

`R__seed_media_assets.sql` is generated by Sync All to Flyway and preserves inactive rows. Migration V137 adds the stable key, uniqueness constraint, and promotion timestamp.
